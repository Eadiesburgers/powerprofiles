To avoid having to remember the tuned-adm CLI, I put together a simple Bash script to make checking and switching performance profiles a bit more straightforward — and, admittedly, a little more ... "1970s".

Use the sample '.desktop' file and the battery icon to make launching even less hassle.
Your path to the script and icon location will need to be reflected in the '.desktop file'.  
You'll also obviously need to make the usual chmod executable changes and enable launching of the '.desktop' file.
