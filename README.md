To avoid having to remember the tuned-adm CLI, I put together a simple Bash script to make checking and switching performance profiles a bit more straightforward — and, admittedly, a little more ... "1970s".
Use the sample .desktop file and feel free to use the battery icon, your path to the script location and battery icon will need to reflected in the supplied .desktop file.  You'll also obviously need to 
make chmod executable changes and enable launching of the .desktop file.
